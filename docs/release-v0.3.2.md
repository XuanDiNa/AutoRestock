- Fixed automatic block restocking not working on affected server connections.
- Manually tested on Minecraft **1.26.45.01 / 1.26.51.01 / 1.26.52.03**.

Close Minecraft before upgrading. Keep your existing config, logs and `.close` state.
The tested DLL is unchanged; its internal log version remains `0.3.2-test2`.
